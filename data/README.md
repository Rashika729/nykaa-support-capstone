# Synthetic order dataset

`orders.csv` contains 48 fictional order records generated by
`src/nykaa_support/data.py`. Re-running that script recreates the same data.
Names and email addresses are placeholders; this is not customer data.

| Column | Meaning |
|---|---|
| `order_id` | Unique sample order identifier |
| `customer_name` | Fictional customer label |
| `email` | Reserved `.test` placeholder email |
| `product_sku` | Sample product code |
| `product_name` | Sample product name |
| `category` | Product category |
| `quantity` | Number of units ordered |
| `amount_inr` | Fictional total amount in rupees |
| `order_date` | Sample order date |
| `status` | Sample order status |
| `payment_method` | Sample payment type |
| `tracking_id` | Fictional tracking code, when applicable |

These records are only for the capstone demonstration. They do not represent
real Nykaa orders, customers, products, or transaction records.
